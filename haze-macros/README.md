# haze-macros

The `#[derive(Pack)]`, `#[register]`, `#[resource]`, `#[server]`, `#[get]`, `#[post]`, `#[put]`, `#[delete]` and `#[patch]` macros for `haze`.

Use it through `haze`, which re-exports every one of them in every mode, with no feature needed. This crate is not meant to be a direct dependency. See the `haze` documentation for usage.
